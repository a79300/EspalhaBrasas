# Privacy Policy

**Last Updated: October 8, 2025**

## 1. Introduction

This Privacy Policy explains how the Discord Bot ("the Bot", "we", "us", or "our") collects, uses, and protects information when you use our services. We are committed to protecting your privacy and being transparent about our data practices.

## 2. Information We Collect

### 2.1 Data Automatically Collected

When you use the Bot, we may temporarily process:

**Discord User Information:**
- User ID (Discord unique identifier)
- Username and discriminator
- Avatar URL
- Server (Guild) ID where commands are used

**Command Usage Data:**
- Command names used
- Timestamps of command execution
- Parameters provided (e.g., Valorant username#tag)

**LFG Session Data:**
- Creator's Discord ID
- Participant Discord IDs
- Game name
- Session timing information
- Message IDs for session management

### 2.2 Data You Provide

**Valorant Usernames:**
- When using `/stats`, you provide a Valorant username and tag
- This information is sent to third-party APIs to fetch statistics
- We do not permanently store this information

**LFG Information:**
- Game names and times you specify in `/ranked` commands
- This data is temporarily stored only for the duration of the active session

### 2.3 Data We Do NOT Collect

We do not collect:
- Message content (except commands directed at the Bot)
- Private or direct messages
- Voice data
- Email addresses
- Payment information
- Personal identifiable information beyond Discord IDs

## 3. How We Use Your Information

We use collected information to:

### 3.1 Provide Services
- Execute commands you request
- Fetch Valorant statistics from third-party APIs
- Manage LFG sessions and notify participants
- Display map rotation information

### 3.2 Improve Functionality
- Debug errors and fix bugs
- Monitor Bot performance
- Understand usage patterns to improve features

### 3.3 Ensure Security
- Prevent abuse and spam
- Enforce rate limits
- Protect against malicious use

## 4. Data Storage and Retention

### 4.1 Temporary Storage
- **LFG Sessions**: Data is stored in memory only while sessions are active and is deleted when sessions end or the Bot restarts
- **Command Logs**: May be temporarily logged for debugging purposes (typically 24-48 hours)

### 4.2 No Persistent Database
The Bot does not use a persistent database. Most data is:
- Processed in real-time
- Stored only in active memory (RAM)
- Automatically deleted when no longer needed

### 4.3 Server Logs
Basic server logs may contain:
- Command execution timestamps
- Error messages
- These are retained for debugging and are automatically rotated/deleted

## 5. Third-Party Services

### 5.1 Services We Use

**Henrik Valorant API** ([Henrik Dev](https://github.com/Henrik-3/unofficial-valorant-api))
- Used to fetch player statistics
- Receives: Valorant username and tag
- Privacy: Subject to Henrik API's privacy practices
- API Server: discord.gg/X3GaVkX2YN

**TheSpike.gg**
- Used to fetch current map rotation
- No user data is sent to this service
- Only public webpage data is accessed

**Valorant API** (valorant-api.com)
- Used to fetch map names and game data
- No user data is sent to this service
- Only public API data is accessed

### 5.2 Data Sharing
We do not sell, trade, or rent your information to third parties. Data is only shared with third-party APIs as necessary to provide requested services (e.g., sending Valorant username to fetch stats).

## 6. Data Security

### 6.1 Security Measures
We implement reasonable security measures:
- Environment variables for sensitive API keys
- No public exposure of user data
- Limited data retention
- Secure connections to third-party APIs (HTTPS)

### 6.2 Limitations
While we strive to protect your information, no system is 100% secure. We cannot guarantee absolute security of data transmitted to or processed by the Bot.

## 7. Your Rights and Choices

### 7.1 Access and Control
You can:
- Stop using the Bot at any time
- Remove the Bot from your server
- Avoid providing Valorant usernames if you don't want stats looked up

### 7.2 Data Deletion
Since we don't store persistent data:
- LFG session data is automatically deleted when sessions end
- Removing the Bot from your server stops all data processing
- Temporary logs are automatically rotated

### 7.3 Right to Information
You have the right to:
- Request information about what data we process
- Ask questions about our data practices
- Contact us with privacy concerns
